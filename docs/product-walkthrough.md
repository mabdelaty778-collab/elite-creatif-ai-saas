# Product walkthrough

**[Open my original Elite Créatif launch post and four-screen gallery](https://www.linkedin.com/feed/update/urn:li:activity:7412500377901719552/)**

The original gallery shows the product interface I published with the project announcement.
Use the arrows to inspect these screens:

| Screen | What to inspect |
|---|---|
| Lead generation | Google Maps, LinkedIn, Instagram, and file-upload source controls; lead rows, enrichment, and export actions |
| Dashboard | Campaign overview, recent work, and quick actions |
| Campaign management | Campaign creation, search, status filters, and campaign cards |
| Email analytics | Campaign selection and the reporting layout for sending and engagement |

The screenshots show the web dashboard; the linked source snapshot contains a Gradio interface
and FastAPI backend. The web frontend shown in the gallery was not part of this source review.

This is a **product UI walkthrough**, not a live endpoint or an end-to-end test recording.
The displayed counts are not used as verified production metrics. Campaign cards include
unresolved display values, and the gallery does not establish functioning delivery-event
ingestion or conversion attribution. The [engineering case study](engineering-case-study.md)
explains the implementation and the remaining checks.
